# amptool

A Python package for generating 3D models of amphiphilic polypeptides.

- **Version**: 0.1.0
- **License**: Open source
- **Language**: Python ≥3.12
- **Dependencies**: numpy, rdkit

## Overview

amptool is a computational biology/cheminformatics tool focused on modeling protein-like structures with both hydrophilic and hydrophobic characteristics (amphiphilic polypeptides).

## Repository contents

- `pdb_model.py` — PDB file parsing and manipulation
- `icgen.py` — Internal coordinate generation for molecules
- Sample PDB data files (`monomer.pdb`, `all_ala_helix_short.pdb`, `my.pdb`)
- Configuration via `pyproject.toml`
